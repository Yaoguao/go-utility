# wget-mirror-utility

Упрощённый аналог UNIX-утилиты wget -m, написанный на Go.
Позволяет скачать веб страницу по сети

## Особенности

| Флаг   | Описание                                             |
|--------|------------------------------------------------------|
| `-ulf` | Указание ссылки                                      |
| `-d`   | Указание уровня вложенности  `\t`).                  |
| `-o`   | Указание директории куда будет скачана веб страница. | |
